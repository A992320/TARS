# TARS LOADBALANCE — Ubuntu Server 22.04

حزمة التثبيت الكاملة وتحديث جهاز TARS المثبت. تتضمن أحدث إصلاحات LAN وDHCP، اختيار كرت الشبكة الحقيقي عند اختلاف أسماء المنافذ بين السيرفرات، عدادات CPU وRAM الفعلية، وتسجيل الدخول من صفحة TARS مع خيار تذكّرني.

## تثبيت على سيرفر جديد

```bash
curl -fL https://raw.githubusercontent.com/A992320/TARS/main/TARS-LOADBALANCE-ubuntu22.04-full.run -o TARS-LOADBALANCE-ubuntu22.04-full.run
sudo bash TARS-LOADBALANCE-ubuntu22.04-full.run
```

## تحديث جهاز TARS مثبت

```bash
curl -fL https://raw.githubusercontent.com/A992320/TARS/main/TARS-LAN-UPDATE-ubuntu22.04.run -o TARS-LAN-UPDATE-ubuntu22.04.run
sudo bash TARS-LAN-UPDATE-ubuntu22.04.run
```

لا تستخدم ملف التنصيب الكامل كتحديث إذا كنت تريد الإبقاء على محرك الدمج عاملاً؛ ملف التحديث أعلاه يحدّث لوحة الإدارة والخدمات المطلوبة دون إعادة تشغيل محرك الدمج أو جلسات PPPoE. يحفظ نسخة الرجوع ويعيدها تلقائياً إذا فشل فحص التشغيل.

## LAN وDHCP

بعد التثبيت أو التحديث، افتح تعديل مخرج LAN. اختر الكرت الحقيقي مثل ens32 أو ens18 أو enp0s9، ثم عنوان TARS الثابت والقناع ونطاق توزيع DHCP وDNS. عند تغيير الكرت لا تُنسخ عناوين السيرفر القديم افتراضياً. إذا كان اختيار الكرت غامضاً تطلب الواجهة الاختيار. DHCP هنا يوزع عناوين للأجهزة؛ كرت LAN في TARS يبقى ثابت العنوان.

لا يبدأ خادم DHCP تلقائياً على سيرفر جديد قبل ضبط LAN وتفعيله. عند وجود خادم DHCP آخر على الشبكة، يرفض التفعيل لمنع التعارض. لا تستخدم عنوان بوابة راوتر موجود كعنوان TARS.

حدّث الصفحة بـ Ctrl+F5 بعد التحديث. بيانات الدخول الأولى في /etc/tars/initial-login.txt، ورخصة الجهاز الجديد تُفعّل بحسب معرّفه.

الملفات تحتوي المصدر الكامل ومفتاح تحقق عام فقط؛ لا تتضمن إعدادات الجهاز الخاص أو كلمات المرور أو مفاتيح إصدار الرخص.
